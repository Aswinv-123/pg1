What is html?

HTML stands for HyperText Markup Language and it is text based language used to structure and display web pages.

  • Head
  • Body
  • Title

HTML stands for HyperText Markup Language. is the standard markup language for creating Web pages.
HTML describes the structure of a Web page. HTML consists of a series of elements.
HTML elements tell the browser how to display the content.
